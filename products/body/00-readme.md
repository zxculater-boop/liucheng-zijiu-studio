# 台灣 SME《AI 自動化啟動包》v1｜使用說明

**品牌：** 流程自救工作室  
**產品：** 台灣 SME《AI 自動化啟動包》v1  
**目標：** 7 天內上線「第一條」可跑的自動化（n8n + Google + LINE／Email）  
**語言：** 繁體中文  

---

## 你會得到什麼／不會得到什麼

### 會得到
- 選題與 ROI 粗算（`01-topic-selection.md`）
- 三條可實作藍圖（A 詢價建檔、B LINE 工單、C 每日摘要）
- 節點與權限檢查表（`03-permissions-checklist.md`）
- 7 天實作節奏（本檔）

### 不會得到
- 保證「一次就完美上線」的遠端代操
- 可直接匯入的 n8n JSON（可作加購／升級）
- 取代所有員工、或合規法律意見書

**成功定義（第一條上線）：**  
真實觸發 → 資料寫入 Sheet → 通知到達 → 錯誤有紀錄 → 你能自己重跑一次測試。

## 建議工具與帳號（第 0 天先開好）

| 項目 | 建議 | 備註 |
|------|------|------|
| n8n | Cloud 試用或自架 | 本包以 Cloud／標準節點為準 |
| Google | 同一個 Workspace／個人帳號 | Forms、Sheets、Gmail（選用） |
| LINE | 官方帳號 Messaging API **或** Notify | B 藍圖建議 OA；A／C 可用 Notify／Email |
| Email | Gmail／公司 SMTP | 業務通知備援 |
| AI（選用） | OpenAI 相容 API | 摘要、分類；第一條可不接 AI |

**最小權限原則：** 只開這條流程需要的 Scope；金鑰放 n8n Credentials，勿寫進節點明文。

## 7 天計劃（週末實作版也可壓縮成 3 天）

### Day 1｜選題與範圍（60–90 分）
1. 讀 `01-topic-selection.md`，勾選 8 條常見流程中「每週最痛」的 1 條。  
2. 填 ROI：每週小時 × 時薪 × 4.3＝月成本；目標回本 ≤ 4 週。  
3. 寫「做／不做」各 3 點（例：做通知＋建檔；不做自動報價核准）。  
4. **產出：** 一頁範圍聲明（可貼 Notion／文件首段）。

### Day 2｜帳號、權限、空白表（90 分）
1. 依 `03-permissions-checklist.md` 開好 Google／LINE／n8n Credentials。  
2. 建立 Sheet 範本（欄位見對應藍圖）。  
3. 建測試用 Google 表單或 LINE 測試關鍵字。  
4. **產出：** Credential 全部「綠色」；Sheet 有表頭列。

### Day 3｜照藍圖搭骨架（2–3 小時）
1. 選 A／B／C 之一（建議新手先 A）。  
2. 只做：Trigger → 映射欄位 → 寫 Sheet → 通知。  
3. **先不要**加 AI、分支、多管道；骨架通了再擴。  
4. **產出：** 手動執行一次成功（Execution 綠燈）。

### Day 4｜錯誤處理與測試清單（90–120 分）
1. 加上 Error Workflow 或節點級 Continue On Fail。  
2. 缺欄、重複、API 失敗各測 1 次。  
3. 跑完藍圖內「測試清單」打勾。  
4. **產出：** 錯誤會寫入「錯誤紀錄」分頁或通知你本人。

### Day 5｜真實資料小流量（半天）
1. 內部 3–5 筆真實（可去識別）資料跑完。  
2. 對業務／負責人確認：通知文案、欄位夠不夠用。  
3. 調整對應表（對應表見各藍圖）。  
4. **產出：** 負責人說「可以當正式」。

### Day 6｜上線與交接（60–90 分）
1. Workflow Active＝ON；Trigger 改正式來源。  
2. 寫 10 行維運備忘：誰管金鑰、Sheet 網址、如何暫停。  
3. 截圖：節點圖、一次成功 Execution、Sheet 範例列。  
4. **產出：** 可交給同事的「暫停／重啟」說明。

### Day 7｜複盤與下一條（45 分）
1. 量：本週省下約＿小時（對照 Day 1 ROI）。  
2. 列 3 個摩擦點（通知太吵／欄位缺／重複列）。  
3. 從 `01` 選下一條；或決定加 AI 摘要（藍圖 C）。  
4. **產出：** 下週只做「一個」改善，勿一次改三條。

## 三藍圖怎麼選（30 秒）

| 你的痛點 | 選 |
|----------|----|
| 官網／表單詢價漏接、業務不知道 | **A** |
| LINE 重複問一樣的問題、沒人開單 | **B** |
| 每天要人工彙總數字／狀態給老闆 | **C** |

新手預設：**A**。已有 LINE OA 且訊息量大：**B**。A／B 已穩再上 **C**。

## 上線檢查表（第一條）

- [ ] Trigger 為真實事件（非只手動）
- [ ] Sheet 有完整一列＋時間戳
- [ ] LINE 或 Email 有到達指定人
- [ ] 缺必填欄位時不會「靜默失敗」
- [ ] 你能指出哪個 Credential、哪個 Sheet
- [ ] 知道如何 Active＝OFF 緊急暫停

全部勾完＝啟動包承諾已兌現。做不動再找流程自救工作室接案（Starter／Standard）。
