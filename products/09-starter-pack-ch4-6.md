# 第 4 章｜節點設定清單與權限檢查表

## 4.1 通用（每條流程上線前）

| # | 檢查項 | 通過標準 |
|---|--------|----------|
| G1 | Workflow 已 **Active** | 右上角為開啟，不是只 Test |
| G2 | 時區 | Schedule／Cron 為 `Asia/Taipei` |
| G3 | 錯誤通知 | 失敗會通知你（Email 或 LINE），不是靜默死掉 |
| G4 | 測試資料已清或已標記 | `ops` 沒有一堆「測試」列混進正式統計 |
| G5 | 憑證在 n8n Credentials | Token 不在節點明文、不在公開 GitHub |
| G6 | 執行紀錄會看 | 你知道 Executions 裡成功／失敗長怎樣 |
| G7 | 負責人 | 文件寫明誰改 Sheet、誰改 n8n |

## 4.2 藍圖 A｜表單 → Sheet → 通知

| 節點／項目 | 必設 | 常見錯 |
|------------|------|--------|
| Google 表單必填 | 姓名、聯絡、需求 | 空值灌進 Sheet |
| Sheet 分頁 `ops` | 表頭與 Append 對應一致 | 欄位名打錯導致空白欄 |
| Trigger／Webhook／排程 | 三選一已定案並寫進文件 | 以為即時其實 5 分鐘輪詢 |
| Apps Script（若用） | 觸發條件＝表單提交；URL 為 Production | 還停在 Test URL |
| Gmail／LINE 通知 | 收件者是真人；主旨含客戶名 | 寄到自己垃圾測試信箱忘了改 |
| 表單連結權限 | 「可填寫」對象正確 | 公司外不能填或相反全公開個資 |

**權限：** Google 表單／Sheet 用公司帳；n8n 只拿最小編輯範圍。

## 4.3 藍圖 B｜LINE 關鍵字

| 節點／項目 | 必設 | 常見錯 |
|------------|------|--------|
| Channel access token | Long-lived，存在 Credentials | Token 過期或貼錯頻道 |
| Webhook URL | Production＋Verify 綠燈＋Enable | 只 Verify 沒 Enable |
| 簽章驗證 | 正式環境必做 | 被乱打 webhook 灌工單 |
| 事件過濾 | 只處理 text message | 貼圖／追蹤事件報錯整條停 |
| replyToken | 先回覆再慢操作 | Token 過期回失敗 |
| OA 後台關鍵字 | 與 n8n 不重複 | 客人收到兩則回覆 |
| Sheet 工單 | userId＋原文＋status | 只有回覆沒留案 |

**權限：** LINE 後台管理員至少 2 人（防離職全鎖）；Messaging API 與 OA 綁同一帳。

# 第 5 章｜對外報價話術（跟老闆／客戶怎麼講）

## 5.1 核心公式（背下來）
**省下的時間 × 時薪（或機會成本）× 12 個月 ＞ 建置費 → 就該做。**

例：每天少貼 30 分、時薪以 400 元計 → 月省約 4,000 → 年約 48,000。  
單點 12,800 或啟動包 1,490 都遠低於年省；成長包 38,000 仍常年內回本。

## 5.2 對內（說服自己老闆／主管）— 30 秒版
> 我們現在〔漏詢價／重複貼 Excel／每天彙整報表〕，一個月大概浪費〔〕小時。  
> 我想先做一條最小自動化：〔表單→通知→建檔〕，預算〔1,490 自己做／12,800 請人單點〕。  
> 兩週內看得到有沒有少漏單；有效再擴，無效就停，不綁年約。

## 5.3 對客戶（你若是接案方）— 開口詢價
> 先不談大系統。你們最煩的是哪一件：漏訊、貼資料，還是老闆要數字？  
> 我這邊固定三檔：單點 12,800、成長包 38,000（兩到三條＋培訓＋30 天）、整套 88,000 起。  
> 你回我現況三行，我 24 小時告訴你適不適合、建議哪一檔。

## 5.4 異議處理（短回）

| 對方說 | 你回 |
|--------|------|
| 太貴了 | 可以先單點 12,800 或自己買啟動包 1,490 驗證；有效再升級。 |
| 我們會自己弄 | 沒問題；啟動包就是給自己弄。卡在授權／LINE webhook 再叫我。 |
| 能不能再便宜 | 能減範圍（少一條流程），不砍同範圍價錢。 |
| 要保證營收翻倍 | 不保證營收；保證約定流程跑通＋文件＋培訓。 |
| 錢要驗收後一次付 | 標準是訂金 50%／尾款上線前；這是開工與風險配置，不是不信任。 |
| 先做做看不付錢 | 可提供 15 分免費看診（只判斷能不能做）；建置不免費。 |

## 5.5 報價單開口（貼在訊息）
> 報價單 Q-〔〕：建議【成長包 NT$38,000】，含〔勾選的 A/B/C〕，約 10–14 工作天。  
> 付款：訂金 50% 入帳後啟動；尾款 50% 正式上線前。匯款資料見報價單。  
> 有效 14 天。回「同意」並匯訂金即排訪談。

## 5.6 禁止說出口的話
- 「保證你一個月多賺 XX 萬」  
- 「AI 全自動以後都不用人」  
- 「隨便改、無限改到滿意為止」（改成：保固內修 bug；新需求另報）

# 第 6 章｜升級路徑：自己做 vs 請人做

## 6.1 決策樹（照著走）

```
你這週有沒有 4+ 小時可動手？
 ├─ 沒有 → 直接接案「單點／成長包」
 └─ 有 → 買／用啟動包先跑藍圖 A
        ├─ 3 天內跑通 → 自己維護；第 2 條再評估
        ├─ 卡在授權／LINE／簽章 >1 天 → 請人「單點救火」
        └─ 需要 2–3 條串起來＋培訓同事 → 「成長包」
還要報表儀表板／多系統／60 天陪跑 → 「營運系統」
```

## 6.2 對照表

| 情境 | 建議 | 預算錨點 |
|------|------|----------|
| 想搞懂、願意自己試 | 啟動包 v1 | NT$990–1,490 |
| 只有 1 個痛點、要代建 | 單點救火 | NT$12,800 |
| 2–3 條＋培訓＋30 天 | 成長包（最常見） | NT$38,000 |
| 端到端營運骨架 | 營運系統 | NT$88,000 起 |
| 上線後要人看著 | 月維運 | NT$6,800／月 |
| 多一條同類流程 | 加購 | NT$8,000 起／條 |

## 6.3 升級話術（啟動包用戶 → 接案）
> 看你已經把 A 跑起來了，這步很賺。  
> 若接下來要串 LINE 工單＋每日摘要、又要訓練行政會用，自己做常再卡 2–3 週。  
> 成長包是一次把 2–3 條做完＋培訓＋30 天小改，預算 38,000。要我依你現有 Sheet 估能不能直接接上嗎？

## 6.4 降級話術（預算不夠）
> 營運系統先不做。我們把範圍收成單點：只做〔表單→通知→建檔〕，12,800，先止血。  
> 跑穩再談第二條，比一次砍價做半套安全。

## 6.5 自己做的「停止線」（碰到就升級）
- Webhook／簽章連續兩天 Verify 不過  
- 需要正式環境權限但你不是管理員  
- 同事拒用 Sheet，需要培訓與 SOP  
- 流程依賴 3 個以上系統且日單量高  
- 你已經加班做自動化超過 1 週仍沒上線  

## 6.6 請人做時你要準備的 brief（可複製）
1. 現在流程（5–10 行）  
2. 工具清單與誰有後台  
3. 成功樣子（可驗收的一句話）  
4. 例外情況（下班、重複送出、垃圾訊）  
5. 預算帶（12,800／38,000／88,000）  
6. 希望上線日  

把這 6 點貼給接案方，可少開一次會。
