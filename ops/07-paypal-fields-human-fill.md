# 收款欄位實填｜僅 PayPal

> 本工作室**只收 PayPal**。報價單不要再放台灣銀行匯款四欄。

---

## 必須由真人填（寄報價前）

| 欄位 | 說明 | 誰填 |
|------|------|------|
| **PayPal 收款信箱** 或 **paypal.me 連結** | 須與 PayPal 帳戶登記一致 | 收款人本人 |
| **幣別** | 建議寫清 TWD 或 USD（與客戶約定） | 窗口 |
| **匯款後通知管道** | 客戶付完截圖／交易號傳哪 | 窗口 |
| **統編／發票**（若開發票） | 成交後向甲方要 | 窗口 |

**禁止：** 把示範字 `paypal.me/example` 原樣寄給客戶。

---

## 報價單付款區塊（可貼）

**付款方式：PayPal  alone**

1. 訂金 50%：確認後、啟動前支付；**入帳後才排訪談與建置**
2. 尾款 50%：**正式上線前**支付
3. PayPal：〔paypal.me/你的帳號 或 收款 Email〕
4. 備註／訊息請註明：報價單編號 `Q-〔〕`
5. 付款後請傳交易截圖或 Transaction ID 至：〔LINE／Email〕

（可加：朋友／家人／商品與服務 — 依你帳戶類型；跨境注意手續費由誰負擔，建議報價註明「PayPal 手續費由付款方負擔」或已含在報價內。）
