# Pro360 達人網上架／接案檢查清單｜逐步點擊版

官網：https://www.pro360.com.tw  
參考：[成為專家 FAQ](https://www.pro360.com.tw/pro/faq/)、[項目與地區](https://www.pro360.com.tw/pro/guide/service-location/)、[推廣服務設定](https://help.pro360.com.tw/hc/zh-tw/articles/360015402911)  
目標：建立專家檔＋服務項目（偏 IT／網站／商業顧問／遠距），報價話術對齊三方案；**主動報價有儲值成本，先免費把檔案與項目設對再儲值。**

> 與 Tasker 差異：Pro360 較偏「案件配對＋付費看客／自動估價」；Tasker 有「我的服務」固價櫥窗。兩邊標題與三價務必一致。

---

## 0. 上架前

- [ ] 準備手機可收簡訊、身分證件（實名／身分驗證）  
- [ ] 文案：標題、簡介、三價、三行提問話術（與 Tasker 同套）  
- [ ] 作品圖 3–6 張（價目卡、流程、n8n／Sheet 示意）  
- [ ] 匯款私密四欄已填（`PAYMENT_PRIVATE.md`）—成交後站外收款用  
- [ ] 決定先「手動挑案報價」或「推廣自動估價」（建議先手動，熟悉後再開推廣控預算）  

---

## 1. 註冊成為專家

1. [ ] 開啟 https://www.pro360.com.tw  
2. [ ] 點右上角 **【成為專家】**（或 Join as a PRO）  
3. [ ] 依步驟選擇／搜尋服務類別：優先找 **網站設計、程式開發、商業顧問、行銷、電腦維修／IT** 等接近項；沒有「n8n」就選最接近＋簡介自填 AI／流程自動化  
4. [ ] 填服務地區：自動化可勾 **遠距服務**；若系統要求地區，可勾你能服務的縣市或「全台」相關選項  
5. [ ] 設定 Email 帳號與密碼  
6. [ ] 完成 **電話驗證** 與 **身分驗證**（依當頁引導）  
7. [ ] 登入後到 **【個人檔案／Profile】** 補完整簡介  

**簡介建議貼（可微調）：**  
> 專做台灣中小企業 LINE／Google 表單／試算表流程自動化（n8n）。三方案：單點 NT$12,800、成長包 NT$38,000、營運系統 NT$88,000 起。遠端交付，7–14 天上線。

---

## 2. 項目管理（配對核心）

8. [ ] 右上角 **【我的帳戶】** → **【項目管理】**  
9. [ ] **新增服務項目**（相關能接的可多加一點，提高配對；但不要勾你完全不會的）  
10. [ ] 每個項目設定：  
    - **服務方式**：勾 **我提供遠距服務**（必要時再勾上門）  
    - **服務範圍**：遠距為主可放寬；若案量太多再收斂地區  
    - **工作條件**：依實際可接條件勾（預算帶、案件類型）  
11. [ ] 儲存後回來檢查：項目是否出現在列表、狀態為可接案  

---

## 3. 價格表／報價訊息（推廣或檔案用）

12. [ ] 在項目設定中找 **價格表**（若難製表可關價格表、改「洽談後報價」）  
13. [ ] 建議價格表（對齊我們方案）：  
    - 單點流程建置｜NT$12,800  
    - 成長包（2–3 條＋培訓）｜NT$38,000  
    - 營運系統｜NT$88,000 起  
14. [ ] **預設估價／報價訊息**貼：  
> 您好，我專做 n8n＋LINE＋Google 自動化。請用三行告訴我：①現在怎麼處理 ②每週花多少時間 ③最痛的一點。我 24h 內回建議方案（12,800／38,000／88,000 起）與時程。  

---

## 4. 檔案包裝（提高信任）

15. [ ] 上傳作品／案例圖（即使是示意流程也可以，標明「示意」）  
16. [ ] 服務說明寫清：含什麼、不含什麼、遠端、付款 50/50  
17. [ ] 回覆速度設定／營業訊息：標示「通常 X 小時內回」  
18. [ ] 與 Tasker 服務頁標題、三價、CTA **一字級對齊**（避免買家兩邊比到不一致）  

---

## 5. 開始接案（手動報價）

19. [ ] 進入案件／工作列表，篩選關鍵字：自動化、LINE、表單、Google、行政、系統、網站後台  
20. [ ] 評估案件是否真適合（遠端、有線上工具）再報價——**客戶讀取報價才扣儲值**（依官方現行規則；以站內說明為準）  
21. [ ] 報價金額：寧可對準 12,800 或 38,000，避免亂開低價壞錨點  
22. [ ] 報價說明用第 5 章話術＋附三行提問  
23. [ ] 記下：`日期｜案件｜報價｜是否讀取｜是否成交`  

---

## 6. 推廣服務（可選，控預算）

24. [ ] 【我的帳戶】→【項目管理】→選項目  
25. [ ] 開啟 **自動估價**（或預約服務；預約需先設服務時段）  
26. [ ] 設基礎條件（方式／範圍／工作條件）  
27. [ ] 設價格表＋**每週預算上限**（寧願先低預算試 1 週）  
28. [ ] 達上限會暫停配對—每週看一次成效再加預算  
29. [ ] 官方法：多為「客戶主動聯繫才扣款」類機制，仍以當頁說明為準  

---

## 7. 成交後（平台外＋存證）

30. [ ] 關鍵條件盡量留在站內訊息  
31. [ ] 正式範圍用我們報價單（已實填匯款）或平台建議流程  
32. [ ] 訂金入帳 → 成交 SOP 階段 0  
33. [ ] 公開 repo 的 `ops/CHANNELS.md` 補上 Pro360 專家頁網址  

---

## 卡住速查

| 現象 | 作法 |
|------|------|
| 沒有「我是專家／我的服務」 | 先補完專家檔案與實名認證 |
| 配對太少 | 項目管理多加相關項目；遠距勾滿；簡介加關鍵字 |
| 配對太雜／太多 | 收斂地區與工作條件；關掉不熟項目 |
| 儲值／扣款疑慮 | 先讀站內收費說明；新帳建議小額儲值＋只報高適配案件 |
| 客戶只想極低價 | 引導啟動包思維或單點；不接無限修改 |

## 完成定義

- [ ] 專家身份＋電話／身分驗證完成  
- [ ] 項目管理至少 1 個遠距項目可接  
- [ ] 簡介與三價與 Tasker 一致  
- [ ] 報價訊息模板已存  
- [ ] CHANNELS.md 有 Pro360 連結（或註記「待貼」）  
- [ ] 本週至少手動評估 5 案（報或不報都記）  

**建議節奏：Tasker 固價櫥窗＋Pro360 挑案報價雙軌；同一套三價與話術，不要兩邊開打價格戰。**
