# Tasker（出任務）上架檢查清單｜逐步點擊版

官方依據：[新增服務說明](https://www.tasker.com.tw/help/article/101)、[2025 改版 5 步驟](https://www.tasker.com.tw/articles/detail/794)  
目標：刊登「AI／n8n 自動化」服務，**主力價成長包 NT$38,000**；最多同時曝光 **3 筆**服務。

---

## 0. 上架前（未完成不要點新增）

- [ ] 註冊並登入 https://www.tasker.com.tw  
- [ ] 【帳戶中心】完成手機、信箱、**實名認證**（未認證常無法正常接案／提案）  
- [ ] 專家檔案：頭像、簡介、可接案類型已填  
- [ ] 文案備好（標題／長文案／三價／回覆話術）  
- [ ] 圖片 1–6 張備好（JPG/PNG、每張 <5MB）：價目卡、流程示意、工具截圖  
- [ ] 匯款四欄私密實填已完成（見 `07-bank-fields-human-fill.md`）—站內若走托管另當別論，私訊報價仍可能用得到  

---

## 1. 進入「我的服務」

1. [ ] 登入後點頂部或選單 **【我是專家】**  
2. [ ] 點 **【我的服務】**  
3. [ ] 點右上角 **【➕ 新增服務】**  
4. [ ] 確認目前已曝光服務 < 3 筆（滿 3 要先下架或改其中一筆）  

---

## 2. 填服務名稱與定價

5. [ ] **服務名稱**貼：  
   `幫你把 LINE／表單接到自動流程｜n8n 客製自動化（7–14 天上線）`  
6. [ ] **服務定價**填：`38000`（若只能一個標價；三方案細節寫進內容）  
7. [ ] 若有「方案／交付項目」可新增多筆，建議建三項：  
   - 單點救火 — NT$12,800  
   - **成長包 — NT$38,000**（標成推薦）  
   - 營運系統 — NT$88,000 起  

---

## 3. 服務內容（對應官方欄位）

8. [ ] **服務範圍**：2–3 條 n8n 流程；含 LINE／Google 表單／Sheet／通知；含培訓 45 分、上線後 30 天小改  
9. [ ] **合作方式**：遠端；訂金 50%／尾款上線前；工具 n8n＋既有帳號授權  
10. [ ] **交付與排程**：10–14 工作天；交付流程圖＋操作說明＋權限交接  
11. [ ] **注意事項／不含**：客製 UI、ERP 深串、駐場、第三方授權費；範圍外另報 NT$8,000 起／條  
12. [ ] 貼上架長文案（痛點→做法→三價→CTA）  
13. [ ] CTA 保留：`先傳最煩的 1 個流程，24h 內回能否做、多少錢、多久`  

---

## 4. 類別、技能、圖片

14. [ ] **服務類別**：最多 10 項—選最接近「IT／網站／商業／自動化／AI」（以當頁可選為準，勿亂勾）  
15. [ ] **技能專長**：填 `n8n`、`LINE Official Account`、`Google Sheets`、`Google Forms`、`流程自動化`、`AI 自動化`  
16. [ ] **上傳作品**：點【上傳作品】，最多 6 張；勿模糊、勿無關圖  
17. [ ] 建議圖序：①三價目表 ②詢價→通知流程 ③n8n 節點示意 ④Sheet ops 欄位 ⑤交付物清單  

---

## 5. 送出審核

18. [ ] 整頁預覽一次（標題有無被截斷、價格是否正確）  
19. [ ] ✅ 勾選服務條款  
20. [ ] 點 **【確認送出】**  
21. [ ] 進入審核→通過後公開；被拒依理由改類別／補具體交付物／去掉誇大保證字眼再送  

---

## 6. 刊登後 24h

22. [ ] 複製服務公開網址 → 寫入 repo `ops/CHANNELS.md`  
23. [ ] 開推播／Email，詢價目標 **1 小時內回**（用三行提問話術）  
24. [ ] 無痕模式打開自己的服務頁核對  
25. [ ] 同步 Pro360 標題與三價（若也上）  
26. [ ] Sheet 建：`詢價數｜報價數｜訂金數`  

---

## 7. 有人來訊時的操作順序

27. [ ] 站內聊聊貼三行提問  
28. [ ] 定案後可用站內 [報價單產生器](https://www.tasker.com.tw/toolbox/quotation) 做三方案簽署，**或**寄我們的報價單模板 PDF  
29. [ ] 若走平台案件托管：依官方「案主付款保管→交付→驗收→提領」；若走站外匯款：嚴格用成交 SOP＋實填匯款，關鍵條件仍留在站內聊聊存證  
30. [ ] 訂金確認 → SOP 階段 0  

---

## 8. 與「我要接案／提案」並行（可選加流量）

31. [ ] 【我要接案】搜尋：自動化、LINE、表單、Google、行政流程  
32. [ ] 點【我要提案】：初次估價填 12800–38000（依案件）、說明貼痛點解法＋連到「我的服務」  
33. [ ] 提案送出後無法改—送前再核一次價格與時程  

---

## 卡住速查

| 現象 | 作法 |
|------|------|
| 沒有「我是專家／我的服務」 | 先補完專家檔案與實名認證 |
| 無法新增（已 3 筆） | 下架或編輯舊服務騰位 |
| 審核退回 | 交付物寫具體、分類收斂、刪「保證營收」 |
| 只想競標不想固價 | 固價服務仍建議留著當作品集；案件用提案 |

## 完成定義

- [ ]「我的服務」頁公開可開  
- [ ] 名稱＋定價 38000＋三方案說明齊  
- [ ] ≤6 張圖、類別與技能已填  
- [ ] 審核通過或已送審  
- [ ] 公開 URL 已記；詢價話術在手機
